# srckit-play

> Part of [srckit](https://github.com/srckit-org/srckit) — developer tools suite

Interactive JavaScript and HTML playgrounds.

## Features

- **JS** — Write and run JavaScript with console output capture
- **HTML** — Write HTML with live iframe preview

## Tech Stack

React 19 · MUI 9 · Tailwind CSS 4 · TypeScript 6 · Vite 8

## Getting Started

```bash
npm install
npm run dev
```
